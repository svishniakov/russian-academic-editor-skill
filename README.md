# Russian Academic Editor Skill

Скилл для Codex и совместимых agent-skill рантаймов. Он помогает редактировать русскоязычный академический текст: уточняет формулировки, убирает канцелярит и шаблонность, сохраняет смысл, термины, цифры и ссылки.

Скилл не предназначен для обхода антиплагиата, AI-проверок или авторских проверок. Его задача другая: добросовестное академическое редактирование, аккуратный пересказ и проверка ссылочной честности.

## Для чего использовать

- Перефразировать русский академический абзац без потери смысла.
- Убрать канцелярит, пустые вводные конструкции и машинную шаблонность.
- Сделать стиль спокойнее, точнее и естественнее.
- Сохранить термины, цитаты, ссылки, имена, даты, числа и методологические оговорки.
- Проверить, не потерялась ли ссылочная честность после правки.

## Чего скилл не делает

- Не помогает обходить антиплагиат.
- Не обещает прохождение AI-detectors.
- Не маскирует заимствования.
- Не придумывает источники, цитаты, выводы или результаты исследования.
- Не удаляет ссылки ради «уникальности».

## Пример вызова

```text
Use $russian-academic-editor to polish this Russian academic paragraph while preserving meaning, terminology, and citations:

В рамках данного исследования важно отметить, что цифровизация образовательной среды является ключевым фактором, который способствует повышению эффективности взаимодействия между преподавателями, студентами и административными структурами.
```

Ожидаемый тип результата:

```text
Вариант:
В этом исследовании цифровизация образовательной среды рассматривается как фактор, влияющий на взаимодействие преподавателей, студентов и административных подразделений.

Что изменено:
- Убраны канцелярские конструкции.
- Сохранён исходный смысл без добавления новых выводов.
- Формулировка стала короче и спокойнее.
```

## Принцип

Этот repo фиксирует не «обход проверки», а редакторскую дисциплину: текст должен быть авторским, точным, понятным и корректно ссылаться на источники.
